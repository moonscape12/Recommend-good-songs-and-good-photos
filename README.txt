은하수에 밤하는 전체 사이트

접속 코드: galaxy2026

사용 방법
1. 이 ZIP을 압축 해제합니다.
2. index.html을 브라우저로 열면 됩니다.
3. 같은 브라우저에서는 한 번 접속하면 코드를 다시 입력하지 않습니다.
4. 사진/노래는 현재 사용 중인 브라우저의 저장공간에 저장됩니다.

중요
이 버전은 '바로 실행되는 전체 다운로드본'입니다.
서로 다른 휴대폰에서도 게시물을 공유하려면 Firebase 같은 서버형 저장소 연결이 추가로 필요합니다.

이미지 넣기
assets 폴더에 아래 파일을 넣으면 홈페이지 배경이 적용됩니다.
- home.jpg
- music-photo.jpg
- character.png
